# Desafio Cibersegurança — Brute Force com Medusa

Este projeto documenta um laboratório prático de ataques de força bruta usando **Kali Linux** e a ferramenta **Medusa**, contra ambientes vulneráveis como **Metasploitable 2** e **DVWA**. O objetivo é entender como esses ataques funcionam e quais medidas de prevenção adotar.

## Estrutura do repositório

- [docs/config.md](docs/config.md) – configuração das máquinas virtuais.
- [docs/testes.md](docs/testes.md) – documentação com passo a passo da execução dos testes.
- **wordlists/** – wordlists simples usadas nos testes.

---

> ⚠️ Este projeto deve ser executado **apenas em ambientes controlados** (VMs isoladas) e **com permissão**. Não realize ataques em redes ou sistemas não autorizados.
